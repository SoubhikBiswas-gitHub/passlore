# Security policy

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/soubhik-biswas/passlore/security/advisories/new). Include affected code or URLs, reproducible steps, impact and any safe demonstration. Do not publish live credentials, real generated passwords or another person's data.

The current `main` branch receives security fixes. Reports are assessed by the repository owner; there is no guaranteed response time or paid bounty.

Do not run destructive tests, access other people's data or overload the live service. Report vulnerabilities in third-party services to their owners.
